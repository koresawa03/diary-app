# ADR-0002: アプリ使用状況は相手に共有しない

- 日付: 2026-11-11
- 状態: 採用

## 状況
「よく使ったアプリ」を相手と共有したかった。しかし iOS でアプリの利用状況を取れるのはスクリーンタイムAPI（Family Controls / DeviceActivity）だけで、規約でその利用データを端末の外に出すことが禁止されている。

## 決定
アプリ利用時間は「本人だけが見られる振り返り」（F-09）として端末内で表示する。相手には送らない。

## 検討した他の案
- Android だけ共有する: Android では取得できるが、OS で体験が変わり、iPhone と Android のカップルで不公平になるため見送り。
- iOS でも別の方法で推定して送る: 規約の解釈が曖昧で、ストア審査でリジェクトされる危険があるため見送り。

## 結果・影響
目玉機能の1つを諦めたが、規約違反でのリジェクトの危険がなくなった。「生データは端末に残す」（ADR-0003）というプライバシー重視の方針とも揃った。
