# Claude Code に渡すプロンプト集

上から順に、1つずつ Claude Code に貼って進める。1つ終わるごとに動作確認 → コミット → update.md に「完了」を付ける。セッションの切れ目では「baton書いて」と頼む。
各プロンプトは「設計書を読む → 計画を説明 → 実装 → 説明」の流れになるように書いてある。

---

## 0. 最初のセッション（リポジトリの理解）

```
CLAUDE.md と docs/design.md、supabase/migrations/0001_init.sql を読んでください。
読んだ上で、
1. このアプリの目的を3行で
2. MVP（フェーズ2〜3）で作るものの一覧
3. 設計書の中で矛盾や曖昧な点があれば列挙
を答えてください。コードはまだ書かないでください。
```

## 1. Expo プロジェクトの作成（フェーズ2）

```
このリポジトリの直下に Expo（TypeScript、Expo Router）のプロジェクトを作ってください。
- 既存の CLAUDE.md、docs/、supabase/、.claude/ は残す
- TypeScript は strict
- package.json に lint / typecheck / test のスクリプトを用意（ESLint、tsc --noEmit、Jest）
- CLAUDE.md の「フォルダ構成」に沿って空のフォルダと index を作る
着手前に、実行するコマンドと作るファイルの一覧を見せてください。
```

## 2. 1日の区切りユーティリティ（共通ルール）

```
設計書の「共通ルール：1日の区切り」に従い、src/lib/date.ts を作ってください。
- 端末のタイムゾーンで、午前4時区切りの entry_date（YYYY-MM-DD）を返す関数
- 締め時刻（翌朝4時）を過ぎたかを判定する関数
境界値（3:59、4:00、日付またぎ、月末）を含む Jest のテストも書いてください。
テストを書いてから実装し、最後に npm test の結果を見せてください。
```

## 3. Supabase の接続とサインイン（F-01、S-02）

```
F-01 と S-02 を実装してください。
- src/lib/supabase.ts にクライアントを作る。URL と anon key は環境変数から読む（example.env を参照）
- Apple でサインイン（iOS）、Google でサインイン（両OS）
- 初回サインイン時に profiles に行を作る（表示名を入力させる）
ネイティブ側の設定（Apple / Google の管理画面でやること）は、私が手でやる手順として別にまとめてください。
```

## 4. ペア招待（F-02、S-03）

```
F-02 と S-03 を実装してください。
- create_circle、create_invite、accept_invite の RPC を呼ぶ
- 招待リンク（ディープリンク）と QR コードの表示・読み取り
- 設計書の例外（期限切れ・使用済み・人数上限）のエラー表示
RPC が返すエラー名（invite_invalid など）と画面の表示文言の対応表も作ってください。
```

## 5. 自動日記の下書き生成（F-03）

```
F-03 を実装してください。まずは iOS だけでよいです。
- 写真（PhotoKit）、訪問した場所（Core Location の訪問記録）、歩数（HealthKit）を取得するネイティブモジュールを modules/ に作る
- 取得結果を設計書の EntrySummary の形にまとめ、expo-sqlite に下書きとして保存
- 権限がない項目は下書きに出さない
最初に、ネイティブモジュールの API（TypeScript 側の関数の形）を提案して、私の確認を取ってから実装してください。
```

## 6. タイトル・ひとこと・自動送信（F-04、F-05、S-04、S-05）

```
F-04、F-05、S-04、S-05 を実装してください。
- 共有項目の設定（circle_members.share_settings）。初回は必ず設定画面を通す
- 寝る前の通知（初期値 22:30）
- 締め時刻を過ぎた最初の起動 / バックグラウンド処理で entries に送信。3日以上前の下書きは破棄
- 共有がオフの項目は summary に入れない
ADR-008 の内容に沿っているか、最後に自己チェックしてください。
```

## 7. タイムライン（F-06、S-06、S-07）

```
F-06、S-06、S-07 を実装してください。タイトルを見出しにしたタイムラインと、スタンプでの反応。
```
